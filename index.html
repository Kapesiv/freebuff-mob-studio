Attach Part

Choose which bone the part attaches to and which surface it sits on. The surface is the outermost face of the model in that direction — the part grows the creature.

The part inherits this bone's rotation and animation (e.g. head → the part follows head movement).
2×2 places two rows along the surface — Spore-style clusters (spikes, legs, horns).

Download Resource Pack

Model, textures and animations ready in a folder structure. Bedrock = addon (resource_pack + behavior_pack) — the mob spawns immediately. Java = resource pack + data pack: /function ns:summon_id summons a named mob, spawn.json is a mod template.

Bedrock downloads as a .mcaddon file — Minecraft opens it directly for installation (resource_pack + behavior_pack).
